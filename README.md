# Jercog Lab website (upgrade preview)

A redesigned, single-page version of the [Pablo Jercog Team](https://sites.google.com/view/pablojercogteam/) site (Computational Neuroscience of Memory, Instituto Cajal, CSIC). Same content and photos as the Google Site, with a new layout.

- Plain HTML/CSS/JS, no build step: open `index.html` or serve the folder.
- Photos live in `img/`.
- Works on phones, follows the system light/dark setting, and loads YouTube videos only when clicked.
